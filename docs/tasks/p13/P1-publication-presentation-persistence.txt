CANONICAL PRESENTATION SEMANTICS

`description`:
- optional/nullable;
- string input only when supplied;
- trim surrounding whitespace at the configuration boundary;
- blank/whitespace-only input normalizes to absent/null rather than invented copy;
- maximum 500 Unicode code points;

- optional/nullable;
- string input only when supplied;

`accentColor` / `accent_color`:
- optional/nullable;
- string input only when supplied;
- trim surrounding whitespace;
- blank/whitespace-only input normalizes to absent/null;
- accept only a six-digit hexadecimal sRGB value with leading `#`;
- normalize accepted hex digits to canonical uppercase `#RRGGBB` form;
- reject shorthand, alpha-channel, CSS functions, color names, arbitrary CSS, and malformed values.
