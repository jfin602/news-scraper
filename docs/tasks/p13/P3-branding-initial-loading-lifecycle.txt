ROOT-CAUSE FIX FOR R7KM
The current implementation paints generic Publication copy (`News feed`) in initial HTML and resets to that same generic copy before first-page requests. Remove that placeholder-first behavior at its source.

Initial server HTML while Publication data is unresolved MUST:
- contain no visible fake/generic Publication heading such as `News feed`;
- contain no fake description/logo/headline content;
- provide a neutral document title suitable for unresolved state, e.g. `Loading publication…`;
- provide an intentional loading region/status that can be centered/styled by the existing stylesheet;
- remain useful to assistive technology with a status message such as `Loading publication…`;
- remain topic-independent.

Do not "fix" R7KM by rendering the old placeholder and hiding it after JavaScript starts. Browser tests must be able to delay `/api/feed` and observe that generic Publication copy was never visibly present during the pending state.

PUBLICATION DOM
