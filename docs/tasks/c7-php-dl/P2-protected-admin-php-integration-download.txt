P1 PRODUCER -> P2 CONSUMER CONTRACT
Consume exactly the P1 package result boundary:

`download request -> P1 package service -> {safe filename, application/zip, deployed version, bounded ZIP bytes} -> HTTP response`

P2 must not:
- traverse `integrations/php`;
- maintain a second file allowlist;
- parse top-level `package.json` to discover the version;
- generate `VERSION`/metadata/config templates;
- implement CRC/ZIP encoding;
- access machine credential records or plaintext tokens to construct the package.

If any of those are necessary, stop and repair/replan P1 rather than duplicating producer-owned behavior.

ADMIN ROUTE
Add one dedicated admin GET route with this canonical path:

`GET /admin/api/php-integration/download`

Keep it logically separate from credential CRUD. Prefer a small dedicated route registrar/service consumer rather than adding package behavior to `DistributionCredentialAdministrationService` or its repository.

The route must:
- exist only inside the same admin-enabled API perimeter as current protected administrator routes;
- call only the P1 package producer;
- return status `200` on success;
- set `Content-Type: application/zip`;
- set a safe attachment `Content-Disposition` using exactly the P1 filename;
- set the exact bounded byte body; set `Content-Length` when consistent with current Express conventions;
- preserve the existing admin response security/no-store headers;
- not add permissive CORS;
- not accept credential/Profile/version/path query parameters;
- not read request body state;
- not expose local filesystem paths, source manifest internals, stack traces, or package-generation details.

A package-unavailable/build failure must return a bounded admin-safe failure response, preferably `503` with a stable machine-readable code such as `integration_package_unavailable`, without leaking the underlying file/path/error. Use existing error handling conventions where they cleanly fit. Do not catch unrelated programmer errors merely to misclassify them.

Administration-disabled behavior must remain fail-closed: the route is absent/404 just like other admin routes.

Do not interpret the ordinary machine distribution bearer token as admin authorization and do not add a machine-auth path to this download.

ADMIN UI
In the existing Distribution Credentials workspace heading/actions, add one page-level action labeled exactly:

`Download PHP Integration`

It is not attached to an individual credential row and must remain available even when zero credentials exist, because the package itself is generic.

Prefer the simplest accessible same-origin download control supported by the current page: a normal anchor styled with existing button classes and pointing to `/admin/api/php-integration/download`, relying on server `Content-Disposition` for attachment behavior. Do not add JS blob/object-URL machinery unless source inspection proves a normal link cannot satisfy the browser/download contract.

Keep `Refresh Credentials` and all create/rotate/revoke controls unchanged. Do not automatically embed/copy a token into the ZIP and do not imply that downloading the package saves the one-time token.

ONE-TIME CREDENTIAL SECRECY MUST REMAIN UNCHANGED
The current credential workspace displays plaintext only immediately after create/rotate and clears it on dismiss/deactivate/reload. Preserve that exact behavior.

The download control must not:
- append the token to a URL/query/fragment;
- place it in filename/headers/package bytes/localStorage/sessionStorage;
- read `state.token` in `credentials.js`;
- associate the package with a credential lookup ID;
- make a credential metadata request as a prerequisite for download.

If the UI can remain purely declarative in `admin-page.ts`, prefer leaving `credentials.js` untouched.

RUNTIME COMPOSITION

Avoid eagerly generating the ZIP during Web startup if that would turn a package-file problem into a complete Web startup outage. Prefer the smallest lazy/on-request or safely memoized producer behavior established by P1, with package failure contained to this admin download route.
