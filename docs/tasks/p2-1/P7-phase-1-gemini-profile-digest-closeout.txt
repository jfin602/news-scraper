At minimum challenge:

- old supported production Profile rows missing AI defaults after upgrade;

### Input/provider security

- cutoff off-by-one and clock nondeterminism;
- Profile `resultLimit`/filters bypassed by AI query;

- Source summary/page says “ignore instructions,” requests another URL, asks for key/system prompt;

- URL Context returns paywall/error/unsafe or a redirect/annotation URL different from stored destination;

### Lifecycle/concurrency

- two Workers hit slot boundary simultaneously;
- manual click races scheduled claim;
- Worker dies after claim before provider call, during provider call, or after provider success before activation;
- provider succeeds twice due uncertain retry;
- config changes during in-flight generation;
- digest disabled during in-flight generation;
- canonical Article disappears during in-flight generation;
- newly arriving Article outside top 20 triggers incorrectly;
- oldest Article ages out with no replacement and causes unnecessary call;
- no-overlap old digest remains indefinitely;
- failed replacement rewrites `generatedAt` or pretends freshness.

### v1/PHP

- digest changes between page 1/page 2;
- `304` returned after digest-only change;
- invalid digest turns Article API into 503;
- valid digest carries internal attempt/error/config fields;
- PHP initial page valid digest, continuation malformed/different digest;
- PHP optional invalidity preserves stale prior digest into new Article revision;
- pre-digest local state falsely treated corrupt;
- visitor code reaches upstream/provider because digest absent.

### Admin

- Profile A response paints Profile B panel;
- double-click Generate now causes two calls;
- machine token reaches admin AI route;
- missing Gemini key crashes Web startup;
- browser sends arbitrary URL/prompt/model/key field;
- provider failure response leaks raw exception;
- disabled AI still exposes old digest publicly.

Classify each plausible failure as protected, requiring a bounded repair/test, requiring Terra refactor handoff, or requiring normal replanning/contract change.
