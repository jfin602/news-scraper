## `top-tag.php`

Add root-level customer-editable `top-tag.php` as the first-party fallback/reference presentation required by Project Contract Law 13.

Requirements:

- consume only the P3 stable customer local-read entrypoint;
- never require `src/bootstrap.php`, cache/manifests, `sync.env`, upstream URL, bearer token, or internal state-store classes;
- render useful server-side output when local state is usable/stale-usable;
- preserve canonical Article order exactly;
- headline anchors use exact stored normalized `originalUrl` values;
- escape all untrusted Publication/Profile/Article/Source/Category/digest generated text for HTML context;
- treat digest generated text as untrusted plain text, not trusted HTML/Markdown;
- handle empty Articles and unavailable/never-synced/disabled/stale-cutoff states safely and simply;
- when digest exists, render a small useful digest section with truthful generation/freshness information and application-resolved support links; when digest is null, Article rendering remains normal;
- do not filter, rerank, deduplicate, regroup, recategorize, reinterpret Source trust, or change destinations;
- no JavaScript required for the core content;
- no News Scraper/Gemini request on visitor render.

Keep the source intentionally editable: PHP and actual HTML elements should be laid out on separate readable lines. Do not build the entire table/page as one concatenated HTML string.

The file is instructional/customer-owned markup. Avoid framework-specific classes or customer-specific wording that makes it look authoritative.
