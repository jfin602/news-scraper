A. STATIC HTML PROFILE / PARSER — LEVEL 2 + LEVEL 5

PASS 2 — ERROR / EDGE-CASE ADVERSARIAL REVIEW
After Pass 1 is green on a candidate tree, perform a separate fresh review derived from actual source rather than merely checking existing test names.

At minimum challenge:
- empty/whitespace/malformed HTML and non-UTF/multibyte boundary inputs;
- huge/deep documents and selector worst cases near every configured bound;
- selector features the dependency supports but the governed subset intends to reject, including expensive pseudo behavior;
- script/event-handler/src/srcset/style/iframe/embed/link markup that could tempt resource loading or unsafe rendering;
- title/link selectors matching unexpected node types, missing href, blank href, javascript/data/mailto URLs, and relative/fragment/query links before downstream policy;
- mixed valid/invalid rows where invalid rows greatly outnumber valid rows;
- zero matched roots and roots that all fail required extraction;
- optional date/category/summary fields missing, repeated, or overbound;
- Source with RSS admission phrases plus both RSS and HTML endpoints;
- HTML run after a redirect where relative links depend on terminal URL;
- HTML endpoint receiving XML/feed/JSON/binary media and RSS endpoint receiving HTML;
- conditional 304 after a prior successful HTML run;
- parser/profile revision changed while older jobs/runs exist and historical run revision remains truthful;
- repeated/no-op profile saves and rapid concurrent admin profile replacement;
- RSS↔HTML switch with invalid draft profile or existing conditional validators;
- worker interruption/failure after run start but before parser/finalization/runtime-state application;
- repeated HTML collection of the same canonical URL and same URL across different Sources;
- duplicate processing/manual moderation behavior triggered by HTML-created Articles;
- preview body exactly at/over JSON and sample limits;
- preview attempt containing secret sentinels/scripts and parser-library exception text;
- proof preview cannot reach DNS/network/database even through an accidental dependency/import;
- stale preview response after switching endpoint/Source/type;
- save/check-now/preview button race combinations;
- admin diagnostics containing long selector/input-derived strings;
- N+1/unbounded profile/run reads at intended MVP scale;
- accidental package-lock creation or browser dependency use in Worker code.

Classify each plausible finding as:
1. already protected by implementation plus meaningful executed evidence;
2. governed behavior clear but coverage weak — add/strengthen a bounded regression;
3. concrete bounded Phase 18 defect — repair and add focused regression coverage where practical;
4. meaningful behavior-preserving refactor — stop and use the Terra High handoff below;
5. material ambiguity/hard defect — stop for model escalation/replanning/correction.
