LOCKED BEHAVIOR
Canonical concept and public/admin semantics:
- internal/server field: `digestStyleGuidance`;
- protected admin label: `Digest writing style` (browser field is P2);
- stored value: `string | null`;
- hard maximum: **500 Unicode code points** after canonical application normalization;
- blank or whitespace-only input means `null` / no custom guidance;
- nonblank input is normalized to a stable trimmed plain-text value while preserving meaningful internal text/newlines;
- subject- or audience-specific wording is allowed because this is Profile configuration, not shared-engine topic branching;
- this value may influence tone, voice, audience, formality, and similar writing qualities only;
- it never replaces fixed News Scraper instructions and cannot weaken Article/Profile grounding, URL allowlists, secret handling, tool selection, response schema, plain-text rules, support-ID validation, or output bounds;
- saving configuration does not synchronously call Gemini;
- changing the canonical stored guidance changes `digestInputIdentity` even if the ordered Article IDs are unchanged;
- the setting itself is server-side admin configuration and must not be serialized into the public v1 digest, PHP LKG/local-read digest shape, customer cache, logs, or provider diagnostics.
