CORRECTION GOAL
The existing Profile AI digest admin form exposes:

```text
Digest writing style
[ textarea ]
Optional; blank uses the default digest writing style.
Up to 500 Unicode code points.
```

An administrator can load one Profile, see its current canonical guidance, edit/save/clear it alongside existing digest settings, switch Profiles without stale state leakage, and invoke Generate now separately through the unchanged action.

ADMIN HTML
In `src/app/web/admin-page.ts`:
- add an accessible **Digest writing style** label and `<textarea name="digestStyleGuidance">` in the existing AI digest configuration form;
- reuse existing wide-field/form styling rather than creating a new presentation system;
- helper text says optional, blank uses normal/default digest writing style, and server limit is 500 Unicode code points;
- do not call it a system/developer prompt, arbitrary instructions, URL field, or provider control;
- preserve current cadence/status/Generate-now UI and all existing admin presentation behavior;
- expose no Gemini key/model/tool/raw-prompt/provider-body control.

Do **not** use native `maxlength="500"` unless you prove it matches the contract's Unicode code-point count. HTML/browser length semantics use UTF-16 code units and can incorrectly reject 500 valid astral/emoji code points. Prefer accurate helper text plus server-authoritative validation over a subtly incorrect client limit. Do not create a duplicate client normalization framework merely to mirror P1.

ADMIN CLIENT DATA FLOW
In `src/app/web/admin/profiles.js`:
- populate textarea from `ai.configuration.digestStyleGuidance ?? ''` whenever the selected Profile AI state is rendered;
- include `digestStyleGuidance` explicitly in the existing protected configuration PUT body with enabled/lookback/max;
- send blank as blank; P1 owns blank→null normalization;
- after successful save, render returned canonical server state rather than assuming typed text is canonical;
- preserve the existing message/behavior that saved settings take effect through later scheduled evaluation unless Generate now is explicitly clicked;
- preserve manual Generate now as a separate request;
- preserve selected-Profile stale-response guards: delayed Profile A AI reads/saves must not repaint Profile B;
- do not copy identity hashing, prompt composition, URL neutralization, DB rules, audit rules, or code-point normalization into browser code;
- do not put style in query strings, localStorage, public feed state, or URLs.
