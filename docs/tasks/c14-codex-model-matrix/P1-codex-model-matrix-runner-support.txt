- Recommended configuration: `Terra High`.
- Model-family basis: the current runner does not support Luna yet, and this task changes the runner/parser contract itself; Terra is the least-expensive currently executable family with appropriate shared-tooling reasoning headroom.

- Estimated usage: `Moderate`.

- Escalation trigger: unexpected Codex CLI/version-format behavior or parser coupling that requires architectural redesign rather than the bounded matrix/preflight extension described here.
- Escalation target: `Terra Ultra`.
- Estimate confidence: `High`.
- Efficiency rationale: the implementation boundary is explicit and testable; no Sol capability is justified.

- use the already observed `codex --version` result returned by launcher resolution; do not add a second version invocation;
- parse the numeric semantic version from normal output such as `codex-cli 0.147.0` without adding a new dependency;
