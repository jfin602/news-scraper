PHASE 10 EXIT GATE TO PROVE
Phase 10 is green only when observed evidence against the exact accepted executable tree proves:
1. due approved + active + enabled endpoints are automatically scheduled when singleton Publication collection is active;
2. durable jobs survive process boundaries and one endpoint has at most one queued/running job at a time;
3. multiple scheduler/Worker processes cannot create duplicate outstanding work or simultaneously claim one job;
4. scheduled jobs execute through the same canonical endpoint collection path as manual collection;
5. the existing shared per-endpoint PostgreSQL advisory lock still prevents overlapping endpoint execution;
6. conditional ETag/Last-Modified state is persisted and supplied safely, with correct successful-200 replacement, successful-304 merge, and no validator commit after downstream/transport failure;
7. one durable job attempt correlates to at most one Collection run and crash recovery does not duplicate that run;
8. transient scheduled failures retry only within the bounded three-attempt chain using deterministic bounded backoff/jitter;
9. permanent/validation/parser/deterministic failures do not retry indefinitely;
10. repeated failures apply bounded cooldown and later scheduler selection respects it;
11. endpoint health is derived as `unknown`, `healthy`, `delayed`, `degraded`, or `unhealthy` without conflating approval/lifecycle/operational state;
12. global/per-Source/per-host collection capacity is enforced across Worker processes and one saturated Source/host does not unnecessarily block unrelated work;
13. capacity/endpoint-lock contention does not count as a failed Collection run or consume a retry attempt;
14. one Source/job failure does not interrupt unrelated queued collection;
15. Worker scheduler/consumer/recovery loops run continuously without busy-looping or overlapping scheduler passes;
16. in-flight durable leases are renewed and stale ownership cannot terminalize work;
17. graceful shutdown stops new work, allows in-flight work to finish or remain durably recoverable, and closes resources once;
18. recent queue/endpoint/run outcomes, timing, failures, cooldown, retry chain, and derived health are diagnosable from durable state without console-only dependence;
19. Web/API public-feed reads remain independent/readable during collection failures and no Web/API inline collection path exists;
20. all inherited singleton, Source approval, network-safety, Article identity/provenance, Collection-run accounting, public-feed eligibility/order/original-link, and regression behavior remains green.
