REQUIRED ADVERSARIAL AREAS
Exercise representative combinations covering:

1. COLLECTION APPROVAL / NETWORK SAFETY
- unapproved/paused/disabled/archived Source/endpoint cannot reach transport;
- unsupported scheme/port/domain is rejected before contact;
- localhost/private/link-local/metadata/special-use IPv4 and IPv6 forms are rejected;
- IPv4-mapped IPv6 cannot bypass classification;
- mixed DNS answers fail closed when any considered address is unsafe;
- redirect hops rerun scheme/domain/port/DNS/address validation;
- redirect loops/limits remain bounded;
- validated-address binding prevents unchecked second-DNS destination selection.

2. FETCH / RESOURCE ABUSE
- timeout, header, redirect, wire/decompressed response, parser/document/item/field limits remain enforced;
- compression/decompression cannot create unbounded memory behavior inside governed limits;
- invalid media type cannot switch an RSS endpoint into HTML behavior or vice versa;
- Source failure remains isolated from unrelated Sources/jobs.

3. CONTENT SAFETY
- publisher title/summary/category/author/error-like text remains inert in public/admin rendering;
- sanitization does not execute scripts/event handlers or load subresources;
- HTML listing collection remains static: no Article-page, pagination, image/script/style/frame/embed/browser fetch;
- preview remains no-network and no-database/job/run state mutation;
- parser/preview diagnostics do not echo unbounded raw HTML or dependency internals.

4. ADMIN REQUEST / RESOURCE INTEGRITY
- every unsafe admin mutation remains protected by the existing request-integrity control;
- malformed/missing integrity header fails before mutation;
- duplicate JSON keys, wrong content type, malformed JSON, oversized bodies, unknown/invalid fields fail safely;
- Source/endpoint/Category/Relevance/Article/duplicate relationships cannot be crossed through mismatched route/body identifiers;
- singleton Publication remains configuration rather than an authorization/tenant key;
- no native admin account/session is introduced.

5. ERROR / SECRET LEAKAGE
- database/transport/parser/configuration failures do not reveal database URLs, passwords, tokens, SQL, stack traces, raw publisher bodies, or unbounded details through HTTP responses or structured process diagnostics;
- Web/Worker startup/shutdown failure records remain bounded JSON diagnostics;
- hostile Source/operator strings cannot forge trusted structured fields in emitted JSON objects.

TEST QUALITY
- Prefer controlled fake resolvers/transports and deterministic hostile fixtures for network/content cases.
- Use real disposable PostgreSQL where the attack depends on resource relationships, rollback, or durable mutation.
- Use Chromium only for security behavior that genuinely requires a browser DOM/CSP/client boundary; do not duplicate all admin browser flows.
- No security suite may silently skip because PostgreSQL/browser/tooling is unavailable. Missing prerequisites must fail clearly when the suite requires them.
