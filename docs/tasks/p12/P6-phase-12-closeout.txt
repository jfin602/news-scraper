- no public `limit`, offset, page number, ranking, or total-count contract was introduced;
- `/api/feed` remains the single canonical discovery/feed endpoint and `/` remains the canonical page;
- direct URL, refresh, Apply, Reset, Back/Forward, and Load more maintain coherent browser state;
- cursor/load-more depth is not canonical root URL state;
- stale first-page/continuation responses cannot corrupt newer browser state;
- continuation failure preserves already rendered rows and supports bounded retry;
- public headline links remain exact stored `original_url`;
- shared engine/client logic remains topic-independent.
