## Pass 1 — Contract and evidence review

Review the integrated implementation against every Phase 2 roadmap exit condition and governing invariant.

At minimum verify from source and executed evidence that:

### Canonical outward authority

- there is one governed Article eligibility/order/destination authority used by both the reference public feed and Distribution Profile selection;
- Source approval/lifecycle, Article visibility, ungrouped-or-Primary Duplicate suppression, effective Categories, effective headline/date, canonical ordering, and exact stored `original_url` are not independently reimplemented by competing consumers;
- Source operational state, endpoint state/health, Collection-run state, and Publication collection state remain orthogonal to retained outward eligibility where governed;
- internal order state preserves PostgreSQL microsecond precision across keyset boundaries.

### Existing `/` and `/api/feed`

- both still require Publication `public_status = public`;
- both retain existing discovery/filter/cursor/public-page behavior and output shape;
- public keyword search retains its governed fields and does not silently become Profile phrase matching;
- public discovery pagination remains its existing non-frozen reference contract rather than inheriting distribution snapshot semantics;
- generic public error/not-found behavior and direct publisher destinations remain preserved.

### Distribution Profile snapshot

- Profile state is consumed through the Phase 1 aggregate rather than reconstructed from child-table SQL in a competing read path;
- missing/draft/disabled/active states remain typed producer outcomes;
- only active Profiles produce distributable results;
- Profile selection runs after canonical eligibility and only narrows it;
- include/exclude/Category semantics are exactly OR within list, AND across dimensions, exclusion wins;
- phrase matching is deterministic case-insensitive literal substring matching over effective headline/author/summary only;
- effective moderated Category state is used;
- Profile filtering occurs before the result/history bound;
- multi-Source results use canonical global ordering;
- active reads are coherent across Profile aggregate, Publication name, and Article selection through the implemented read-snapshot mechanism;
- Publication `public_status` and Source operational state do not change Profile output merely by themselves.

### Guaranteed producer fields

- the transport-independent result supplies all fields Phase 4 needs without exposing persistence internals: Profile key/name, Publication name, Article ID/headline/original URL/effective date/date source/null publishedAt/author/summary/imageUrl, Source key/name, and effective Category key/name collection;
- nullable fields remain nullable and Categories remain an explicit empty collection when empty;
- exact stored publisher destination is preserved.

### Revision and continuation

- revision is deterministic and content/semantic-state-derived, not `updated_at`, transaction ID, random value, or persistent snapshot row;
- revision material includes every state whose change must invalidate the bounded snapshot and excludes explicitly irrelevant state;
- cursor codec is separate from the legacy public discovery cursor and is versioned/bounded/opaque/Profile-bound/revision-bound/position-bound;
- continuation uses the canonical microsecond-safe order tuple and no offset pagination;
- unchanged traversal has no omissions/repetitions;
- relevant mutations produce typed `snapshot_changed` before mixed data can be returned;
- malformed/tampered/profile-mismatched/current-revision-invalid-position cursors fail boundedly;
- no HTTP/API/auth semantics have leaked into the transport-independent producer.
