PHASE 8 EXIT GATE TO PROVE
Phase 8 is green only when observed evidence against the exact accepted tree proves:
1. Article visibility is durable with canonical `visible` / `hidden` / `archived` states;
2. existing Phase 7 Articles migrate to `visible` and new Articles default/baseline to `visible`;
3. later unchanged/material Source observations preserve non-visible state and do not reinterpret visibility as Source-derived material change;
4. an existing Publication can be deliberately transitioned `private <-> public` through the generic operator mechanism while ordinary bootstrap remains create-if-absent/no-overwrite;
5. public-feed reads expose only a public Publication's approved active Sources and visible Articles;
6. Publication collection activity, Source operational state, and endpoint/run operational/health state are not incorrectly used as historical feed suppression gates;
7. feed effective date uses parsed `published_at` else `first_seen_at`, exposes the source branch, and orders deterministically by effective date DESC, first_seen DESC, Article id ASC;
8. the Phase 8 feed is bounded to the defined 100 newest eligible rows after canonical ordering;
9. every returned item uses `display_title`, Source display name and stored `original_url`, never silently substituting `canonical_identity_url`;
10. public empty Publication returns HTTP 200 with empty items;
11. missing and private Publications are indistinguishable as public HTTP 404;
12. dependency/read failures are bounded secret-safe HTTP 503;
13. a real public HTTP request through the Web/API process returns a real persisted eligible Article from disposable PostgreSQL deterministically;
14. Web/API remains read-only for Source collection and existing health/process behavior remains intact.

The inherited testing contract also requires focused + broader regressions, actual Level 4 PostgreSQL evidence for persistence/feed claims, no required skipped/zero-selected substitute suites, and a durable exact-tree closeout artifact.

PHASE 8 BEHAVIOR EVIDENCE MATRIX
The durable closeout artifact must identify concrete tests/commands proving each area below.

A. ARTICLE VISIBILITY / MIGRATION — LEVEL 4
Prove:
- production migrations from zero include the visibility migration;
- representative Phase 7 Article history upgrades to `visible`;
- new Articles have `visible` baseline;
- PostgreSQL accepts only `visible`, `hidden`, `archived`;
- hidden/archived state survives later unchanged/material Source persistence;
- Source-derived `updated`/`unchanged` semantics remain truthful;
- Article identity/cardinality/observation provenance remains intact.

B. PUBLICATION EXPOSURE AUTHORITY — LEVELS 3/4
Prove:
- explicit generic local operator transition `private -> public`;
- explicit transition `public -> private`;
- invalid/missing input does not mutate/create unrelated state;
- fresh initial Publication configuration uses intended public tech-demo state;
- ordinary bootstrap after an operator change does NOT overwrite persisted `public_status`;
- command/database failures do not leak credentials/connection detail.

C. PUBLIC FEED ELIGIBILITY — LEVEL 4
Prove:
- requested Publication must be public;
- Source must be approved + active;
- Article must be visible;
- another Publication's rows cannot bleed in;
- public `active_for_collection = false` remains readable;
- approved active paused/disabled Source remains readable;
- endpoint operational/lifecycle/health and latest-run state do not silently hide otherwise eligible retained Articles;
- no duplicate-group/role persistence exists merely for Phase 8.

D. FEED DATE / ORDER / BOUNDS — LEVEL 4
Prove:
- parsed `published_at` is effective date;
- missing/invalid date falls back to `first_seen_at`;
- read model exposes `published_at` versus `first_seen_at` source;
- ordering is effective date DESC, first_seen DESC, Article id ASC;
- repeated reads are deterministic;
- 101+ eligible rows return exactly canonical newest 100;
- public zero-eligible rows return Publication identity + empty items.

E. SAFE READ MODEL / ORIGINAL DESTINATION — LEVEL 4
Prove:
- stable Article id, effective date/source, display headline, Source display name and original URL are returned;
- stored `original_url` is returned even when `canonical_identity_url` deliberately differs;
- no normalized title, canonical identity URL/digest, external ID, summary/content, observation/run/endpoint IDs or other internal fields are exposed.

F. HTTP CONTRACT — LEVEL 3
Prove with injected deterministic route dependencies:
- success exact minimal JSON;
- explicit ISO timestamp serialization;
- empty public feed = 200;
- `undefined` = canonical 404;
- private/missing cannot be distinguished at route level;
- synthetic read failure with secret-like detail = bounded 503 with no leak;
- health routes remain unchanged.

G. REAL POSTGRESQL -> WEB/API -> HTTP — LEVEL 4
Prove through actual migrated disposable PostgreSQL + production reader + Express listener + real local HTTP request:
- a persisted visible Article under public Publication/approved active Source is returned;
- headline/Source/date/source/original destination match stored state;
- public empty returns 200 empty list;
- private returns the same 404 behavior as missing.

H. WEB PROCESS / FAILURE BOUNDARIES — LEVEL 3

- unavailable DB still permits Web listener/liveness;
- readiness returns 503;
- feed returns bounded 503;
- database secret is absent from stdout/stderr/HTTP;
